# Funcionalidades

## Lista

- adicionar produto;
- definir quantidade;
- definir preço unitário;
- calcular subtotal;
- calcular total;
- remover item;
- editar item diretamente na tabela.

## Mistério

- esconder lista;
- controlar tentativas de visualização;
- escolher item secreto;
- impedir escolha de produto já cadastrado;
- cronômetro;
- pistas progressivas;
- comparação normalizada de texto;
- recuperação da lista;
- glitch visual;
- total temporariamente incorreto.

## Interface

- layout responsivo;
- identidade visual pastel;
- mensagens contextuais;
- estados de interface controlados por JavaScript.
