# Desenvolvimento

## Origem

Check Again surgiu inicialmente como um exercício de lista de compras em HTML, CSS e JavaScript.

A intenção era praticar:

- formulários;
- arrays;
- objetos;
- manipulação do DOM;
- cálculos;
- eventos.

Durante o desenvolvimento, surgiu a ideia de transformar o comportamento da lista em uma pequena narrativa interativa.

A partir disso, o projeto deixou de ser apenas uma aplicação utilitária e passou a funcionar como um minigame de dedução.

## Evolução do conceito

### Primeira versão

Lista de compras tradicional.

### Segunda versão

A lista começa a desaparecer quando o usuário tenta visualizá-la.

### Terceira versão

Introdução de um item secreto.

### Quarta versão

Sistema de pistas e cronômetro.

### Quinta versão

Recuperação da lista, glitch e anomalia temporária no total.

## Direção atual

O foco do projeto é desenvolver Check Again como um pequeno jogo web de dedução, mantendo a lista de compras como elemento narrativo e mecânico.
