# Game Design — Check Again

## Conceito

Check Again começa se comportando como uma aplicação comum de lista de compras.

O jogador adiciona produtos, quantidades e preços normalmente.

A ruptura acontece quando ele tenta visualizar a lista.

O sistema afirma que a lista está disponível, mas ela não aparece.

Depois de novas tentativas, surge a possibilidade de que algo esteja faltando.

A partir desse momento, a aplicação revela sua verdadeira natureza: um pequeno jogo de dedução.

## Premissa

Existe um item ausente.

O jogador precisa descobrir qual produto completa a lista.

O sistema oferece pistas progressivamente enquanto mantém a lista escondida.

## Experiência desejada

O jogo deve transmitir:

- curiosidade;
- estranhamento leve;
- humor;
- sensação de descoberta;
- surpresa.

Não é um jogo de terror.

A interface continua delicada e amigável mesmo quando começa a se comportar de maneira inesperada.

## Identidade visual

A direção visual utiliza:

- tons pastel;
- formas arredondadas;
- tipografia amigável;
- mensagens educadas;
- animações discretas.

O contraste entre aparência confortável e comportamento estranho é parte da identidade do jogo.
